# 沪深300指数隐含波动率每日简报 V2

自动化系统，每日获取沪深300指数数据，计算历史波动率，**获取真实的隐含波动率(IV)**，生成可视化图表并通过邮件发送简报。

## 🎯 核心功能

- ✅ 自动获取沪深300指数最新数据（通过Tushare API）
- ✅ **多种方法获取隐含波动率(IV)**，自动降级策略
- ✅ 计算20日历史波动率（年化）
- ✅ 生成专业的波动率走势图表
- ✅ 自动发送HTML格式的邮件简报
- ✅ 支持定时任务自动执行

## 🔥 V2版本新特性

### 多层次IV获取策略

脚本会按优先级尝试以下方法获取隐含波动率：

| 优先级 | 方法 | 数据源 | 说明 |
|--------|------|--------|------|
| 1 | **QVIX指数** | AkShare | 中证300股指期权波动率指数（最准确） |
| 2 | **中证波动率指数** | Tushare (000188.SH) | 官方发布的波动率指数 |
| 3 | **历史波动率** | 计算 | 20日滚动年化标准差（备用方案） |

**自动降级机制**：如果某个数据源失败，自动尝试下一个，确保报告始终能生成。

## 注意事项

⚠️ **数据权限**：
- QVIX指数通过AkShare免费获取，无需额外权限
- 中证波动率指数需要Tushare基础权限
- 如果所有IV数据源失败，将使用历史波动率作为备用

⚠️ **邮箱设置**：
- 网易邮箱需要开启SMTP服务并获取授权码
- 授权码不是邮箱登录密码
- 获取方式：邮箱设置 → POP3/SMTP/IMAP → 开启服务 → 获取授权码

⚠️ **交易日限制**：脚本会自动处理非交易日情况，获取最近一个交易日的数据。

## 数据说明

### 隐含波动率 vs 历史波动率

| 指标 | 隐含波动率(IV) | 历史波动率 |
|------|---------------|-----------|
| **定义** | 从期权价格反推的未来波动预期 | 基于历史价格计算的实际波动 |
| **时间维度** | 前瞻性（未来30天） | 回顾性（过去20天） |
| **数据来源** | 期权市场价格 | 指数历史价格 |
| **市场含义** | 市场对未来的预期 | 过去的实际表现 |
| **投资价值** | 衡量市场情绪和风险偏好 | 衡量历史波动水平 |

**关键洞察**：
- IV > 历史波动率 → 市场预期未来波动加大（可能是恐慌或不确定性增加）
- IV < 历史波动率 → 市场预期未来波动减小（可能是信心增强）

## 常见问题

### Q1: 为什么有时候只显示历史波动率？
**A:** 这是正常的降级行为。当QVIX和中证波动率指数都无法获取时（如网络问题、数据源维护等），系统会自动使用历史波动率作为备用。

### Q2: 隐含波动率和历史波动率哪个更重要？
**A:** 两者各有价值。IV反映市场预期，是前瞻性指标；历史波动率反映实际波动，是回顾性指标。两者结合使用效果最佳。

### Q3: QVIX指数是什么？
**A:** QVIX是中证300股指期权波动率指数，类似美股的VIX指数，反映市场对未来30天波动率的预期，也被称为"恐慌指数"。

### Q4: 周末会发送邮件吗？
**A:** 不会。定时任务设置为周一至周五执行，周末不会触发。

### Q5: 如何修改发送时间？
**A:** 需要更新定时任务的Cron表达式。例如改为每天上午9点：`0 0 9 * * 1-5`
